# Contextwise AI Engineering Project Pack

This directory converts the Contextwise curriculum into executable milestone work packages. Start with the project brief, then complete milestone files in order unless an ADR justifies a different dependency path.

## Start Here

1. Read [`PROJECT_BRIEF.md`](PROJECT_BRIEF.md).
2. Complete Milestone 0.
3. Use the retrospective template before tagging every release.
4. Do not begin the next milestone until the exit gate has a recorded decision.

## Working Rule

A milestone is complete only when the feature works, the tests pass, the evaluation evidence is stored, the system is observable, the risks are documented, and the exit gate is signed off.
