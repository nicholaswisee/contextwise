# Contextwise 0.3.0 — Document Ingestion

- Added owner-protected TXT, Markdown, and PDF uploads with durable processing
  status, retry, cancellation, and reprocessing routes.
- Added content-addressed original storage, document versions, extracted text,
  and source segments with page, section, and character-offset provenance.
- Added a PostgreSQL-backed worker that reclaims expired leases and avoids
  duplicate segments on replay.
- Added a 15-document parser baseline, failure tests, security review, and a
  reversible `0004` database migration.

The code commit passed CI. The release tag remains open until the final
milestone gate decision is recorded.
