# Contextwise 0.2.0 — Core Assistant

## User-visible changes

- Added owner-protected conversation creation, listing, retrieval, and message
  APIs.
- Added SSE chat streaming with durable chunk, completion, failure, and
  cancellation state.
- Added idempotent streamed retries, response regeneration, and copied-ancestry
  branches.
- Added context inspection for the exact persisted prompt/model snapshot and
  selected message IDs.
- Added text, image-reference, and file-reference message-part contracts;
  current provider calls remain text-only.

## Architecture changes

- Added conversation, message, and idempotency-request persistence.
- Extended `model_invocations` with conversation linkage and immutable context
  provenance.
- Added reversible Alembic migration `0003_core_assistant`.
- Added deterministic character-based budgeting with a 4096-token combined
  budget and 512-token output reserve.

## Known limitations

- Ownership is a single configured local token, not multi-user authentication.
- The token estimator is approximate and should be replaced only after measured
  evaluation shows a material defect.
- Automatic memory, summaries, retrieval, provider-native multimodal calls,
  real-provider measurements, and external deployment hardening remain
  deferred. Document ingestion is added in the next milestone.
- Milestone 1's credentialed provider comparison and provider review remain
  open as documented predecessor debt; they are outside the single-owner
  assistant release scope.
