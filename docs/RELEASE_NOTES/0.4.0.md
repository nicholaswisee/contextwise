# Contextwise v0.4.0

Milestone 4 adds owner-scoped collections that select existing documents and
publish immutable retrieval indexes. Users can retrieve ranked evidence,
ask for an extractive cited answer, open the stored passage behind a citation,
and inspect a persisted retrieval run. Questions with insufficient evidence
abstain. A cloud embedding adapter and optional gateway answer mode are
available through configuration. Gateway answers with valid citations are
explicitly marked unverified; invalid citations cause abstention.

PostgreSQL now requires the pgvector extension. Migration `0005` creates
collection, index, chunk, and retrieval-run tables plus an HNSW cosine index.
The Docker and CI PostgreSQL images use `pgvector/pgvector:0.8.7-pg16-bookworm`.
Existing document rows and objects are unchanged. Before upgrading a
non-Docker database, install pgvector for its PostgreSQL major version and
back up the database. Upgrading an existing PostgreSQL 16 Docker volume to
the new image should be rehearsed with that volume's backup before production
use. Downgrading removes Milestone 4 tables and their retrieval history;
the vector extension remains installed so other users of it are unaffected.

The default local embedding is deterministic and lexical. The 50-case
synthetic baseline is published in `docs/evaluations/04-rag-report.md`.
Credentialed semantic quality and cross-provider costs are not yet measured.
The local release gate passed with documented debt. The tag is
`contextwise-v0.4-rag`; credentialed semantic-provider quality remains a
separate follow-up.
