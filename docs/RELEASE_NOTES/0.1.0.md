# Contextwise v0.1.0 — LLM Gateway

## User-visible changes

- `POST /v1/generations` generates free-form or registered-schema responses.
- `POST /v1/generations/stream` emits SSE chunks and a completion event.
- `GET /v1/models`, `GET /v1/prompts`, and `GET /v1/invocations/{id}` expose supported configuration and redacted invocation metadata.

## Architectural changes

- Added a provider-neutral `LLMClient` contract with fake and LiteLLM adapters.
- Added PostgreSQL `model_invocations` persistence and migration `0002`.
- Added bounded retries for typed transient provider errors and explicit pre-stream fallback disclosure.
- Added registered Pydantic structured-output validation.

## Known limitations

- Fake provider is the default; no real provider is configured in this environment.
- Streaming fallback is not supported after a stream begins.
- Cost estimates are zero for fake calls.
